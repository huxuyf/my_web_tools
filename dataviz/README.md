# 数据可视化工具

## 功能介绍

这是一个离线可用的数据可视化Web应用，支持从Excel或CSV文件导入数据，并快速生成交互式图表。

## 主要特性

- **离线使用**：所有处理在浏览器本地完成，无需网络连接
- **多格式支持**：支持.xlsx、.xls和.csv格式的文件导入
- **多种图表类型**：支持柱状图、折线图、饼图、散点图等
- **交互式图表**：图表支持缩放、数据提示、图例切换等交互功能
- **拖拽上传**：支持拖拽文件到页面进行上传
- **数据预览**：导入后可预览数据表格内容

## 使用方法

### 1. 准备数据文件

Excel或CSV文件应包含表头行，每一列代表一个数据字段。

### 2. 上传文件

- 点击上传区域选择文件，或直接将文件拖拽到上传区域
- 支持的文件格式：.xlsx、.xls、.csv

### 3. 配置图表

上传成功后：
1. 选择要使用的X轴数据列（通常是时间、类别等）
2. 选择要显示的Y轴数据列（通常是数值）
3. 选择图表类型（柱状图、折线图、饼图等）
4. 点击"生成图表"按钮

### 4. 导出图表

生成的图表可以导出为图片格式。

## 数据格式要求

- Excel文件必须包含表头行
- 表头名称将作为图表的标签和图例
- 数值列应包含有效的数字数据
- 建议数据行数不超过10000行

## 注意事项

- **数据清洗**：确保数据格式正确，避免空值或格式错误
- **内存限制**：大文件可能占用较多内存，建议分批处理
- **兼容性**：需要现代浏览器支持（Chrome、Edge、Firefox、Safari）

## 技术实现

- **前端框架**：原生HTML/CSS/JavaScript
- **样式框架**：Tailwind CSS
- **Excel解析**：SheetJS (XLSX) 库
- **图表渲染**：Apache ECharts

## 浏览器兼容性

支持以下主流浏览器的最新版本：
- Chrome 90+
- Edge 90+
- Firefox 88+
- Safari 14+

## 隐私说明

所有数据处理在用户本地浏览器中完成，不会上传到任何服务器，确保数据安全和隐私。
