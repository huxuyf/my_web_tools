# 文本元素分割与组合工具

## 功能介绍

这是一个用于分割和组合文本元素的Web工具，可以将文本按指定分隔符分割成列表，或将列表元素按指定格式组合成文本。

## 主要特性

- **文本分割**：将文本按指定分隔符分割成独立元素
- **列表组合**：将多个元素按指定格式组合成文本
- **自定义分隔符**：支持自定义分割和组合的分隔符
- **实时预览**：输入后实时显示处理结果
- **一键复制**：支持一键复制处理结果
- **离线使用**：纯前端实现，无需网络连接

## 使用方法

### 文本分割功能

1. 在"输入文本"区域输入要分割的文本
2. 在"分隔符"输入框中指定分割符（如逗号、空格、分号等）
3. 点击"分割"按钮，结果会显示在右侧
4. 点击"复制结果"可复制分割后的列表

### 列表组合功能

1. 在"输入列表"区域输入要组合的元素（每行一个元素）
2. 在"分隔符"输入框中指定组合时使用的分隔符
3. 在"前后缀"输入框中指定每个元素的前缀和后缀（可选）
4. 点击"组合"按钮，结果会显示在右侧
5. 点击"复制结果"可复制组合后的文本

## 使用场景

- **SQL语句处理**：将SQL IN语句的值分割成列表，或将列表组合成IN语句
- **数据清洗**：处理CSV或其他格式文本数据
- **批量处理**：批量修改文本格式
- **代码生成**：根据模板生成代码片段

## 注意事项

- **分隔符识别**：确保分隔符与文本中的分隔符一致
- **空行处理**：空行会被自动忽略
- **特殊字符**：如需使用特殊字符作为分隔符，请确保正确输入
- **大小写敏感**：默认情况下，文本处理是大小写敏感的

## 技术实现

- **前端框架**：原生HTML/CSS/JavaScript
- **样式设计**：响应式布局，支持移动端访问

所有文本处理在用户本地浏览器中完成，不会上传到任何服务器，确保数据安全和隐私。
