# 数据转SQL工具

## 功能介绍

这是一个用于将Excel或CSV数据转换为SQL INSERT语句的Web工具，支持批量数据导入和自动SQL生成，大幅提高数据录入效率。

## 主要特性

- **多格式支持**：支持.xlsx、.xls和.csv格式的文件导入
- **自动生成SQL**：根据数据自动生成INSERT语句
- **自定义表名**：支持自定义目标表名
- **字段映射**：自动识别Excel表头作为数据库字段名
- **批量处理**：支持批量转换数千条数据
- **实时预览**：导入后可预览数据和生成的SQL
- **一键复制**：支持一键复制生成的SQL语句
- **离线使用**：纯前端实现，无需网络连接

## 使用方法

### 1. 准备数据文件

Excel或CSV文件应包含表头行，表头名称将作为数据库字段名。

示例Excel格式：
```
| 姓名  | 年龄 | 部门   | 薪资   |
|-------|------|--------|--------|
| 张三  | 25   | 技术部 | 8000   |
| 李四  | 30   | 市场部 | 9000   |
```

### 2. 导入数据

1. 点击"选择文件"按钮，选择Excel或CSV文件
2. 等待文件解析完成
3. 在预览区域查看导入的数据

### 3. 配置SQL生成

1. 在"表名"输入框中输入目标表名（如：employees）
2. 根据需要调整字段类型（可选）
3. 点击"生成SQL"按钮

### 4. 复制SQL

生成的SQL语句会显示在输出区域，点击"复制SQL"按钮即可复制到剪贴板。

## 生成的SQL格式

```sql
INSERT INTO 表名 (字段1, 字段2, 字段3) VALUES ('值1', '值2', '值3');
INSERT INTO 表名 (字段1, 字段2, 字段3) VALUES ('值4', '值5', '值6');
```

## 数据格式要求

- **表头行**：第一行必须是表头，作为字段名
- **字段命名**：建议使用英文字段名，避免特殊字符
- **数据类型**：工具会自动判断数据类型（字符串、数字、日期等）
- **空值处理**：空单元格会被转换为NULL或空字符串

## 注意事项

- **表名规范**：表名应符合数据库命名规范，建议使用小写字母和下划线
- **字段名规范**：字段名不能包含SQL关键字和特殊字符
- **数据验证**：生成SQL前请验证数据格式和内容
- **批量操作**：大量数据建议分批处理，避免SQL语句过长
- **特殊字符**：字符串中的单引号会自动转义

## 使用场景

- **数据迁移**：将Excel数据迁移到数据库
- **批量导入**：批量导入初始数据到数据库
- **测试数据**：生成测试用的SQL语句
- **数据备份**：将数据导出为SQL格式

所有数据处理在用户本地浏览器中完成，不会上传到任何服务器，确保数据安全和隐私。

## 常见问题

**Q: 支持哪些数据库？**
A: 生成的SQL是标准SQL语句，支持MySQL、PostgreSQL、SQL Server、Oracle等主流数据库。

**Q: 如何处理日期格式？**
A: 工具会自动识别Excel中的日期格式，并转换为标准的SQL日期格式。

**Q: 可以生成UPDATE语句吗？**
A: 当前版本仅支持INSERT语句，后续版本会考虑支持UPDATE语句。
