# 时序图生成器

## 功能介绍

这是一个用于生成时序图（Sequence Diagram）的Web工具，可以根据输入的时间点数据自动生成Mermaid格式的时序图，清晰展示各系统之间的操作顺序和时间间隔。

## 主要特性

- **自动识别参与者**：从输入数据中自动提取所有系统名称
- **自动计算间隔**：自动计算相邻事件之间的时间间隔并显示
- **Mermaid生成**：自动生成标准的Mermaid时序图代码
- **实时编辑**：支持手动编辑Mermaid代码，图表实时更新
- **导出功能**：支持导出为PNG图片或SVG矢量图
- **离线使用**：所有依赖库已本地化，完全支持离线使用
- **示例数据**：内置示例数据，方便快速上手

## 使用方法

### 1. 准备输入数据

数据格式：`时间, 系统名称, 操作描述`

示例：
```
17:56:03, 短信系统, 发送第154条短信
18:15:00, 本地表, 插入
18:17:29, 识别程序, 程序识别
18:18:08, 关停系统, 送关停
18:29:20, 关停系统, 实际关停
```

### 2. 生成时序图

1. 在左侧文本框中输入事件数据（每行一个事件）
2. 点击"生成时序图"按钮
3. 右侧将自动显示生成的时序图

### 3. 编辑Mermaid代码

1. 在页面下方的Mermaid源码编辑器中查看生成的代码
2. 可以手动编辑代码，修改后会自动重新渲染图表
3. 支持所有Mermaid时序图语法

### 4. 导出图表

- **导出PNG**：点击"导出为图片(PNG)"按钮，导出为PNG格式图片
- **导出SVG**：点击"导出SVG"按钮，导出为SVG矢量图

### 5. 快速开始

点击"加载示例"按钮，可快速加载示例数据并生成时序图。

## 数据格式要求

- **时间格式**：HH:MM:SS（24小时制）
- **分隔符**：使用逗号分隔三个字段
- **时间顺序**：建议按时间从早到晚排序
- **系统名称**：可以重复，表示同一系统的多次操作

## 时序图说明

- **参与者**：自动从数据中提取所有系统名称，显示为时序图的参与者
- **时间间隔**：在每个操作后显示与下一个操作的时间间隔
- **箭头方向**：从前一个系统指向下一个系统
- **总耗时**：在图表末尾显示整体流程的总耗时

## 注意事项

- **时间格式**：必须使用HH:MM:SS格式，否则可能导致解析错误
- **最少事件**：至少需要2个事件才能生成时序图
- **文件大小**：建议事件数量不超过100条，以保证渲染性能
- **浏览器兼容**：需要现代浏览器支持（Chrome、Edge、Firefox、Safari）

## 技术实现

- **前端框架**：原生HTML/CSS/JavaScript
- **时序图渲染**：Mermaid.js
- **图片导出**：html2canvas
- **本地化库**：所有依赖库已下载到本地

## 浏览器兼容性

## 隐私说明

所有数据处理在用户本地浏览器中完成，不会上传到任何服务器，确保数据安全和隐私。

## Mermaid语法参考

本工具使用Mermaid时序图语法，常用语法包括：

```
sequenceDiagram
    participant A
    participant B
    A->>B: 消息
    Note right of B: 备注
```

更多语法请参考Mermaid官方文档。
