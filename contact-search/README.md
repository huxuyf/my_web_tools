# 通讯录查询工具

## 功能介绍

这是一个离线可用的通讯录查询Web应用，支持从Excel文件批量导入员工通讯录数据，并提供灵活的查询功能。

## 主要特性

- **离线使用**：所有数据存储在浏览器本地（IndexedDB），无需网络连接
- **Excel导入**：支持.xlsx和.xls格式的Excel文件导入
- **精确查询**：支持按姓名、手机号、短号进行精确匹配查询
- **卡片展示**：以卡片形式清晰展示员工完整信息
- **数据去重**：自动检测工号和邮箱重复，保护数据完整性
- **批量导入**：支持数千条记录的快速导入

## 使用方法

### 1. 准备Excel文件

Excel文件必须包含以下表头（顺序不限）：

| 字段名称 | 说明 | 示例 |
|---------|------|------|
| 部门名称 | 所属部门 | 技术部 |
| 姓名 | 员工姓名 | 张三 |
| 邮箱 | 电子邮箱 | zhangsan@example.com |
| 手机 | 手机号码 | 13800138000 |
| 短号 | 公司短号 | 1234 |
| 职位 | 职位名称 | 软件工程师 |
| 性别 | 性别 | 男 |
| 工号 | 员工工号 | E001 |
| 入职时间 | 入职日期 | 2020-01-01 |
| 详细部门 | 详细部门名称 | 技术部-软件开发组 |
| 公司 | 公司名称 | XX科技有限公司 |

### 2. 导入数据

1. 点击右上角的"导入Excel文件"按钮
2. 选择准备好的Excel文件
3. 等待导入完成（会显示进度和结果统计）

### 3. 查询联系人

1. 在搜索框中输入查询关键词（姓名、手机号或短号）
2. 点击"搜索"按钮或按回车键
3. 查看查询结果（以卡片形式展示）

## 注意事项

- **精确匹配**：查询时必须完全匹配姓名、手机号或短号
- **重复检测**：如果导入的文件中包含与现有数据工号或邮箱重复的记录，会弹出提示并中止导入
- **数据覆盖**：每次导入会覆盖原有数据
- **文件大小**：建议单个Excel文件不超过50MB，记录数不超过10000条

## 技术实现

- **前端框架**：原生HTML/CSS/JavaScript
- **Excel解析**：SheetJS (XLSX) 库
- **数据存储**：IndexedDB (使用Dexie.js简化操作)
- **图标系统**：Unicode Emoji

## 浏览器兼容性

支持以下主流浏览器的最新版本：
- Chrome
- Edge
- Firefox
- Safari

## 隐私说明

所有数据仅存储在用户本地浏览器中，不会上传到任何服务器，确保数据安全和隐私。
