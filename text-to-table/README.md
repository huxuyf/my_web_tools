# 文本转表格工具 - 使用说明

## 功能介绍

文本转表格工具是一个专门用于将OCR（光学字符识别）识别的一列文本转换为多列表格的Web应用。转换后的结果使用Tab分隔，可以直接粘贴到Excel或其他电子表格软件中使用。

## 主要特性

- **简单易用**：粘贴文本，设置列数，一键转换
- **智能处理**：自动保留空行，正确处理不足的列
- **快速复制**：一键复制转换结果到剪贴板
- **批量处理**：支持最多1000行文本转换
- **本地运行**：所有处理在浏览器本地完成，保护隐私

## 使用方法

### 1. 输入文本

将OCR识别的一列文本粘贴到文本框中：

```
苹果
香蕉
橙子
葡萄
西瓜
芒果
```

### 2. 设置列数

在"目标列数"输入框中设置转换后的列数：
- 最小值：2列
- 最大值：10列
- 默认值：2列

### 3. 执行转换

点击"转换"按钮，或使用快捷键 `Ctrl + Enter`

### 4. 复制结果

点击"复制"按钮，将转换结果复制到剪贴板，然后粘贴到Excel中。

## 转换规则

### 按行优先填充

转换采用**行优先顺序**（Row-major）填充，即：

```
输入（6行）：
内容1
内容2
内容3
内容4
内容5
内容6

列数=3，输出：
内容1	内容2	内容3
内容4	内容5	内容6
```

### 不足列数的处理

当输入行数不能被列数整除时，最后一行不足的列会自动填充为空：

```
输入（5行）：
内容1
内容2
内容3
内容4
内容5

列数=3，输出：
内容1	内容2	内容3
内容4	内容5
```

### 空行处理

输入中的空行会被保留为有效内容：

```
输入：
内容1

内容2

列数=2，输出：
内容1
内容2
```

## 常见问题

### Q: 转换后的表格粘贴到Excel显示在一列中？
A: 确保复制时包含了Tab分隔符。如果仍然有问题，可以尝试使用"粘贴特殊"功能，选择"文本"格式。

### Q: 为什么我的空行丢失了？
A: 本工具会保留空行。如果空行丢失，可能是复制时没有正确包含换行符。

### Q: 可以转换超过1000行的文本吗？
A: 当前版本限制为1000行。如果需要处理更多数据，请分批转换。

### Q: 转换结果可以保存为文件吗？
A: 当前版本不支持直接保存文件。您可以先复制结果，然后粘贴到Excel中保存。
