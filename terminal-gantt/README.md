# 终端使用时间甘特图

## 功能介绍

这是一个用于可视化展示终端使用时间分布的Web工具，可以根据输入的时间范围数据生成甘特图，直观展示各任务的时间安排和重叠情况。

## 主要特性

- **时间范围可视化**：将时间范围数据转换为直观的甘特图
- **多任务支持**：支持同时显示多个任务的时间线
- **交互式图表**：支持缩放、拖拽查看时间线
- **自动排版**：自动计算任务位置和时间刻度
- **导出功能**：支持导出为图片格式
- **示例数据**：内置示例数据，方便快速上手
- **离线使用**：纯前端实现，无需网络连接

## 使用方法

### 1. 准备数据

数据格式：每行一个任务，包含任务名称、开始时间、结束时间

示例格式：
```
任务1, 2024-01-01 09:00, 2024-01-01 12:00
任务2, 2024-01-01 10:00, 2024-01-01 14:00
任务3, 2024-01-01 13:00, 2024-01-01 18:00
```

### 2. 输入数据

1. 在文本框中输入时间范围数据
2. 每行一个任务，格式为：`任务名称, 开始时间, 结束时间`
3. 时间格式支持：`YYYY-MM-DD HH:MM` 或 `YYYY-MM-DD`

### 3. 生成甘特图

1. 点击"生成甘特图"按钮
2. 图表会自动显示在下方区域

### 4. 交互操作

- **缩放**：使用鼠标滚轮或触摸板缩放时间线
- **拖拽**：按住鼠标左键拖拽查看不同时间段
- **任务详情**：鼠标悬停在任务条上查看详细信息

### 5. 快速开始

点击"加载示例"按钮，可快速加载示例数据并生成甘特图。

## 数据格式要求

- **时间格式**：`YYYY-MM-DD HH:MM` 或 `YYYY-MM-DD`
- **分隔符**：使用逗号分隔任务名称、开始时间和结束时间
- **时间顺序**：开始时间应早于或等于结束时间
- **日期范围**：建议时间跨度不超过一年，以保证渲染性能

## 图表说明

- **任务条**：每个任务用一条横向的条形表示
- **时间轴**：顶部显示时间刻度
- **任务标签**：左侧显示任务名称
- **颜色区分**：不同任务使用不同颜色区分

## 注意事项

- **时间格式**：必须使用标准的时间格式，否则可能导致解析错误
- **最少任务**：至少需要1个任务才能生成甘特图
- **时间跨度**：建议时间跨度不超过一年，以保证渲染性能
- **浏览器兼容**：需要现代浏览器支持（Chrome、Edge、Firefox、Safari）

## 使用场景

- **项目管理**：可视化项目任务时间安排
- **资源调度**：展示资源使用时间分布
- **日程规划**：规划个人或团队的时间安排
- **数据分析**：分析时间使用模式

## 技术实现

- **前端框架**：原生HTML/CSS/JavaScript
- **甘特图库**：DHTMLX Gantt

## 浏览器兼容性

## 隐私说明

所有数据处理在用户本地浏览器中完成，不会上传到任何服务器，确保数据安全和隐私。

## 常见问题

**Q: 支持哪些时间格式？**
A: 支持 `YYYY-MM-DD HH:MM` 和 `YYYY-MM-DD` 格式。

**Q: 如何调整甘特图的时间范围？**
A: 可以通过鼠标滚轮缩放，拖拽查看不同时间段。

**Q: 可以导出甘特图吗？**
A: 可以使用浏览器的截图功能或打印功能保存甘特图。
