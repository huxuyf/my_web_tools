# 点击复制功能说明

## 功能介绍

在通讯录查询结果中，点击手机号码或邮箱地址可以自动复制到剪贴板，方便用户快速获取联系信息。

## 功能特性

### 1. 点击复制 ✅

**支持的字段：**
- 📱 手机号码
- 📧 邮箱地址

**交互效果：**
- 可点击的字段显示为蓝色，带有虚线下划线
- 鼠标悬停时显示背景高亮效果
- 点击后自动复制到剪贴板
- 显示"已复制到剪贴板"提示信息

### 2. 提示信息 ✅

**Toast 提示：**
- 复制成功：显示"已复制到剪贴板"
- 复制失败：显示"复制失败，请手动复制"
- 提示信息在屏幕底部居中显示
- 2秒后自动消失，带有淡出动画

### 3. 浏览器兼容性 ✅

**现代浏览器：**
- 使用 `navigator.clipboard.writeText()` API
- 支持Chrome、Edge、Firefox、Safari最新版本

**旧版浏览器：**
- 降级使用 `document.execCommand('copy')` 方法
- 确保在各种浏览器环境下都能正常工作

#### 2. 复制函数（app.js）

```javascript
async function copyToClipboard(text) {
    try {
        // 使用现代API复制
        if (navigator.clipboard && navigator.clipboard.writeText) {
            await navigator.clipboard.writeText(text);
            showToast('已复制到剪贴板');
        } else {
            // 降级方案：使用document.execCommand
            const textarea = document.createElement('textarea');
            textarea.value = text;
            textarea.style.position = 'fixed';
            textarea.style.opacity = '0';
            document.body.appendChild(textarea);
            textarea.select();
            try {
                document.execCommand('copy');
                showToast('已复制到剪贴板');
            } catch (err) {
                console.error('复制失败:', err);
                showToast('复制失败，请手动复制');
            }
            document.body.removeChild(textarea);
        }
    } catch (err) {
        console.error('复制失败:', err);
        showToast('复制失败，请手动复制');
    }
}
```

#### 3. Toast提示函数（app.js）

```javascript
function showToast(message) {
    // 移除现有的toast
    const existingToast = document.querySelector('.toast');
    if (existingToast) {
        existingToast.remove();
    }

    // 创建新的toast
    const toast = document.createElement('div');
    toast.className = 'toast';
    toast.textContent = message;
    document.body.appendChild(toast);

    // 2秒后自动消失
    setTimeout(() => {
        toast.classList.add('fade-out');
        setTimeout(() => {
            if (toast.parentNode) {
                toast.parentNode.removeChild(toast);
            }
        }, 300);
    }, 2000);
}
```

## 使用示例

### 场景1：复制手机号码

1. 查询联系人信息
2. 在结果卡片中找到"手机"字段
3. 点击手机号码（显示为蓝色虚线下划线）
4. 看到"已复制到剪贴板"提示
5. 在其他应用中粘贴（Ctrl+V）

### 场景2：复制邮箱地址

1. 查询联系人信息
2. 在结果卡片中找到"邮箱"字段
3. 点击邮箱地址（显示为蓝色虚线下划线）
4. 看到"已复制到剪贴板"提示
5. 在邮件客户端中粘贴（Ctrl+V）

## 注意事项

1. **空值不响应**：如果手机号码或邮箱为空，不会显示可点击样式
2. **单次提示**：连续点击时，旧的提示会立即消失，显示新的提示
3. **自动消失**：提示信息会在2秒后自动消失，不影响用户操作
4. **浏览器权限**：某些浏览器可能需要用户授权才能访问剪贴板
5. **HTTPS要求**：现代浏览器的剪贴板API通常需要HTTPS环境（本地localhost除外）
