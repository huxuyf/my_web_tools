# 文字拼接工具

## 功能介绍

这是一个用于将多个文字元素拼接成SQL IN语句或其他格式的Web工具，支持自定义分隔符、引号和前后缀，方便快速生成批量查询语句。

## 主要特性

- **批量拼接**：将多个文字元素快速拼接成一个字符串
- **自定义格式**：支持自定义分隔符、引号和前后缀
- **SQL IN语句**：一键生成标准的SQL IN语句
- **实时预览**：输入后实时显示拼接结果
- **一键复制**：支持一键复制拼接结果
- **多种模式**：支持普通拼接、SQL IN语句等多种模式
- **离线使用**：纯前端实现，无需网络连接

## 使用方法

### 1. 输入文字

在输入框中输入要拼接的文字，每行一个元素。

示例：
```
张三
李四
王五
```

### 2. 选择拼接模式

- **普通拼接**：用指定分隔符连接所有文字
- **SQL IN语句**：生成标准的SQL IN语句格式

### 3. 配置参数

根据需要配置以下参数：
- **分隔符**：元素之间的分隔符（如逗号、分号等）
- **引号**：每个元素是否加上引号（单引号、双引号或无引号）
- **前后缀**：整个拼接结果的前缀和后缀（可选）

### 4. 生成结果

点击"生成"按钮，结果会显示在下方区域。

### 5. 复制结果

点击"复制结果"按钮，将拼接结果复制到剪贴板。

## 使用场景

### 场景1：生成SQL IN语句

输入：
```
张三
李四
王五
```

配置：
- 模式：SQL IN语句
- 引号：单引号

输出：
```sql
('张三', '李四', '王五')
```

### 场景2：生成逗号分隔列表

输入：
```
apple
banana
orange
```

配置：
- 模式：普通拼接
- 分隔符：逗号

输出：
```
apple,banana,orange
```

### 场景3：生成数组格式

输入：
```
1
2
3
```

配置：
- 模式：普通拼接
- 前缀：`[`
- 后缀：`]`
- 分隔符：逗号

输出：
```
[1,2,3]
```

## 注意事项

- **空行处理**：空行会被自动忽略
- **特殊字符**：如需使用特殊字符，请确保正确输入
- **引号转义**：如果文字中包含引号，会自动转义
- **大小写敏感**：默认情况下，文字处理是大小写敏感的

## 快捷操作

- **清空输入**：点击"清空"按钮快速清空所有输入
- **加载示例**：点击"示例"按钮加载示例数据
- **复制结果**：点击"复制"按钮复制拼接结果

## 常见问题

**Q: 支持哪些引号？**
A: 支持单引号（'）、双引号（"）和无引号三种模式。

**Q: 如何处理包含引号的文字？**
A: 工具会自动转义文字中的引号，确保生成的语句正确。

**Q: 可以同时处理多少个元素？**
A: 理论上没有限制，但建议不超过10000个元素，以保证性能。
